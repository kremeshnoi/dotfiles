# Links

Which path in `$HOME` points where, on which machine.

## The rule

| Machine | How files land in `$HOME` | Why |
|---|---|---|
| Mac without Nix | symlinks into `~/dev/dotfiles`, made by `mac/install.sh` | an edit in the checkout applies at once ([ADR 0005](adr/0005-mac-without-nix.md)) |
| Mac with Nix | real copies from the Nix store, made by `nix/home/copy-files.nix` | no links into the store or the repo ([ADR 0002](adr/0002-copy-home-files-instead-of-symlinking.md)) |
| NixOS under WSL | real copies, same as the Mac with Nix | same |

So symlinks exist only on the Mac without Nix. On the Nix machines a link in `$HOME` that points into `~/dev/dotfiles` or `/nix/store` is a leftover: switch again and it is replaced by a copy.

## Mac without Nix

Every link points into the checkout at `~/dev/dotfiles`, except pgf, which points into its own clone.

| Link | Points to |
|---|---|
| `~/.zshrc` | `mac/zsh/.zshrc` |
| `~/.config/git/config` | `shared/git/config` |
| `~/.config/helix` | `shared/helix` (the whole directory) |
| `~/.local/bin/hx` | `mac/helix/hx`, the wrapper that puts the managed language servers first |
| `~/.claude/skills/<name>` | `shared/claude/skills/<name>`, one link per skill |
| `~/.config/herdr/plugins/config/persiyanov.reviewr/config.toml` | `shared/herdr/reviewr.toml` |
| `~/.local/bin/herdr-git-review` | `shared/herdr/git-review.sh` |
| `~/.glzr/glazewm/config.yaml` | `mac/glazewm/config.yaml` |
| `~/.glzr/glazewm/kill-workspace.sh` | `mac/glazewm/kill-workspace.sh` |
| `~/.config/swiftbar/glazewm.sh` | `mac/swiftbar/glazewm.sh` |
| `~/.config/ghostty/config` | `mac/ghostty/config` |
| `~/.local/bin/pgf` | `~/.local/src/pgf/bin/pgf` |

herdr plugins are not file links but registrations in `~/.config/herdr/plugins.json`, made by `herdr plugin link` with the root in the checkout:

| Plugin | Root |
|---|---|
| `kremeshnoi.workspace-tabs` | `shared/herdr/workspace-tabs` |
| `kremeshnoi.space-colors` | `mac/herdr/space-colors` |
| `persiyanov.reviewr` | installed by herdr from GitHub at `v<reviewr version>`, not a link |

### Not links, on purpose

| File | What it is | Why not a link |
|---|---|---|
| `~/.config/herdr/config.toml` | generated: `mac/herdr/config.toml` + `mac/herdr/space-colors/sidebar.toml` | herdr reads one file and has no include ([ADR 0010](adr/0010-work-only-herdr-sidebar.md)); rerun `install.sh` after editing either |
| `~/.zshenv`, `~/.zshrc.local`, `~/.gitconfig`, `~/.ssh/config`, `~/.pg_service.conf` | per-machine files | not in git ([rules.md](rules.md)) |

### Links `install.sh` removes

`~/.local/bin/herdr-goto`, from the tab picker that is gone, and `~/.local/bin/intelephense` with `~/.local/share/intelephense`, replaced by phpantom. Left over from the setup before `shared/zsh` was split: `~/.config/shell/env.sh`, `~/.config/zsh/ohmyzsh`, `~/.config/zsh/zsh-helix-mode`, `~/.config/zsh/fzf-git-branch.zsh`, and the two directories when they end up empty.

### Checking them

```bash
cd ~/dev/dotfiles
while read -r link target; do
  actual="$(readlink "$HOME/$link")"
  if [ "$actual" = "$target" ] && [ -e "$HOME/$link" ]; then echo "ok      ~/$link"; else echo "WRONG   ~/$link -> ${actual:-missing}"; fi
done <<EOF
.zshrc $PWD/mac/zsh/.zshrc
.config/git/config $PWD/shared/git/config
.config/helix $PWD/shared/helix
.local/bin/hx $PWD/mac/helix/hx
.config/herdr/plugins/config/persiyanov.reviewr/config.toml $PWD/shared/herdr/reviewr.toml
.local/bin/herdr-git-review $PWD/shared/herdr/git-review.sh
.glzr/glazewm/config.yaml $PWD/mac/glazewm/config.yaml
.glzr/glazewm/kill-workspace.sh $PWD/mac/glazewm/kill-workspace.sh
.config/swiftbar/glazewm.sh $PWD/mac/swiftbar/glazewm.sh
.config/ghostty/config $PWD/mac/ghostty/config
.local/bin/pgf $HOME/.local/src/pgf/bin/pgf
EOF
for skill in shared/claude/skills/*/; do skill="$(basename "$skill")"; [ "$(readlink "$HOME/.claude/skills/$skill")" = "$PWD/shared/claude/skills/$skill" ] && echo "ok      ~/.claude/skills/$skill" || echo "WRONG   ~/.claude/skills/$skill"; done
```

Any `WRONG` line: rerun `mac/install.sh`.

## Mac with Nix and NixOS

The same files, as copies. `nix/home/` decides what lands where:

| Path in `$HOME` | Copied from | Machines |
|---|---|---|
| `~/.zshrc`, `~/.zshenv` | generated by home-manager, sourcing `shared/zsh/*.zsh` from the store | both |
| `~/.config/git/config` | generated by home-manager, including `shared/git/config` from the store | both |
| `~/.ssh/config` | generated by home-manager | both |
| `~/.config/helix` | `shared/helix` | both |
| `~/.claude/skills/<name>` | `shared/claude/skills/<name>` | both |
| `~/.config/herdr/config.toml` | `mac/herdr/config.toml` | Mac |
| `~/.config/herdr/config.toml` | `windows/herdr/config.toml` | NixOS |
| `~/.config/herdr/plugins/config/persiyanov.reviewr/config.toml` | `shared/herdr/reviewr.toml` | both |
| `~/.local/bin/herdr-git-review` | `shared/herdr/git-review.sh` | both |
| `~/.local/bin/herdr-nav` | `windows/herdr/herdr-nav` | NixOS |
| `~/.glzr/glazewm/config.yaml`, `kill-workspace.sh` | `mac/glazewm/` | Mac |
| `~/.config/swiftbar/glazewm.sh` | `mac/swiftbar/glazewm.sh` | Mac |
| `~/.config/ghostty/config` | `mac/ghostty/config` | Mac |

herdr plugins are registered from store paths: reviewr built from its release, `kremeshnoi.workspace-tabs` from `shared/herdr/workspace-tabs`. space-colors is not registered on the Nix machines.

The list of copied paths is kept in `~/.local/state/home-manager/copied-files`; a path a new generation drops is removed on the next switch.

## Adding a file

Add it on both sides in the same change: a `link` line in `mac/install.sh` and a `home.file` or `xdg.configFile` entry in `nix/home/`, then a row in each table above. See [runbooks.md § Add a config file](runbooks.md#add-a-config-file-for-a-tool-on-every-os).
